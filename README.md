## 机房怎么选：30+ 位置里，大陆用户要注意两件事

绿云在美国有洛杉矶、达拉斯、芝加哥、圣何塞、Ashburn、杰克逊维尔、堪萨斯城、奥格登等机房，欧洲有阿姆斯特丹、法兰克福、考文垂，加拿大有多伦多，亚太覆盖香港、东京、新加坡、河内、胡志明市，新加坡有 2 个数据中心，东京分 IIJ 和 Softbank 两条线路。

第一件事是**亚太机房流量减半**。同一个套餐，美欧给 2TB，亚太只给 1TB，官方的解释是亚洲带宽成本高。$6 档在亚太机房只有 750GB/月，跑个有下载需求的服务很快就见底。

第二件事是**香港到大陆的直连带宽只有 10Mbps**。这是官网产品页明确写出的限制，很多推荐文章压根不提。如果你的访客主要在国内，除非选的是专门标注 ISP/精品直连的高价套餐（如香港 Premium、东京 CN2 类），普通套餐走的都是标准国际 BGP 路由，晚高峰容易拥堵丢包。面向国内用户的正经业务，绿云的普通套餐撑不起来，配 CDN 或中转是常规操作；对延迟零容忍的场景（游戏服务器、实时音视频），建议直接看别的商家。

## 退款和续费：把钱当作花出去的来规划

这是绿云口碑争议最集中的地方，值得展开说。

退款规则分两层。新客户的第一台 VPS，7 天内可以申请退款；所有特价、促销套餐一律不退款；普通原价套餐的退款也有苛刻前提。第三方评测的措辞更直接：“不要抱着买来试用、不好就退的心态”。

续费方面，价格一般是按套餐原价延续，但有第三方提醒过绿云在续费价上出现过对老用户不友好的调整，因此建议月付或短周期年付，不要一次性锁太长。这也是为什么上面推荐先月付试用——退款指望不上，月付本身就是你的“试用期”。

用户体验的两极也体现在评价上。正面：绿云拿过 LowEndTalk 的 "#1 Top Provider" 和 "#1 Most Stable Provider"，第三方 itechguides 给 7.6/10，认为它适合追求 Ryzen 和 NVMe 的预算型用户。负面：v2ex 上有用户投诉新加坡 CN Premium 机型 SSH 每 20 分钟左右断一次，持续近 20 天。单个案例说明不了全部，但结合它 Unmanaged（无代管）的定位——技术只保证底层网络和母机稳定，不帮你排查系统内的问题——下单前就该有心理预期：出了软件层面的问题，得自己扛。

和同类商家对比一下位置会更清楚。RackNerd 的黑五限量机 $10.60/年（1 核/1GB/25GB/2TB）比绿云任何套餐都便宜，标准年付机还带 30 天退款；搬瓦工、DMIT 有面向大陆的 CN2 GIA 优化线路，价格也更高。如果你要的是绝对低价、或大陆直连优化，这两类商家更合适。绿云的差异化在于：同价位下 10Gbps 端口、NVMe 存储、30+ 机房覆盖（尤其东南亚机房密集），加上支付宝支持。要这些，它值得买；只要最便宜，它排不进第一梯队。

## 按场景的最终选择建议

- **跑网站、博客、轻量 Docker**：RyzenKVM-2，$10/月，NVMe + 2GB 内存是舒服的起步配置。记得部署后建 1GB Swap 并把 swappiness 设为 10，低配机跑 MySQL 不容易 OOM。
- **纯自用、预算极限**：RyzenKVM-1 或 SSDKVM-1，$6/月够了，多花钱买高配对这种负载没意义。
- **备份仓库、存文件**：等 Storage VPS 或周年庆的 Storage 特价补货，平时没必要用常规套餐当硬盘。
- **面向国内用户的服务**：普通套餐别直接上，先想清楚 CDN/中转方案，或选明确标注直连优化的机型；预算允许的话，CN2 GIA 类商家是更对症的选择。
- **编译、转码、量化等持续吃 CPU 的任务**：绿云共享型套餐的条款限制连续占满 vCPU，会被限速甚至关机，这种情况应该看 EPYC VDS 专属资源线，别硬上共享机。

下单前最后确认三件事：机房和线路写对了没有（特价机不退，选错只能认）；要不要先用 $6 月付测试一周再考虑年付；优惠码在你的套餐上是否真的生效。确认完这三点，👉 打开 GreenCloud 套餐页选机房下单，亚太机房的流量记得按美欧的一半来规划。
